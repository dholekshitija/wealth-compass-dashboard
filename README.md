# wealth-compass-dashboard
• Developed an interactive financial analytics dashboard in Power BI as part of the Microsoft Power BI course on Udemy. 
• Transformed raw data using Power Query and implemented complex DAX measures to calculate financial metrics and time-based 
insights. 
• Implemented data modeling and relationships to improve report accuracy and interactivity. 
• Designed visual reports to track income, expenses, savings, and investment performance over time.
